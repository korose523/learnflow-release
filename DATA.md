# Data sources and terms

| Dataset | Used for | Where the scripts expect it | Terms |
|---|---|---|---|
| ASSISTments 2009-2010 skill builder (corrected) | contribution drift, selection sensitivity, experienced difficulty | `data/assist09_corrected.csv` | free use as stated by the provider; no redistribution right is inferred, so the file is not included |
| DBE-KT22 (doi:10.26193/6DZWOH) | teacher-label criterion | `data/dbe_kt22/csv/Questions.csv`, `data/dbe_kt22/csv/Transaction.csv` | Australian Data Archive custom analytical-use conditions; no redistribution. Question identifiers, teacher labels and per-item scores are therefore not included in any result file here |
| Junyi Academy learning activity dataset | response-disjoint IRT criterion | `data/junyi/` | CC BY-NC-SA 4.0 |
| XES3G5M | exploratory check in `optimized_experiments.py` | `data/XES3G5M/` | MIT (official repository) |

We acknowledge the original DBE-KT22 investigators and the Australian Data Archive; they bear no responsibility
for this secondary analysis or its interpretation.
